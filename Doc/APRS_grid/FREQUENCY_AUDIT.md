# 频率及接收站核查（2026-10-09）

范围：气球当前的地面VHF AX.25、1200 bps AFSK。LoRa、D-STAR、DMR、HF、卫星及9600 bps不是同一种可直接互通的接收网络。

## 原版区域复核

|区域|候选MHz|结论与主要依据|
|---|---|---|
|美国、加拿大、墨西哥|144.390|保留，APRS.org北美惯例；不是每个电台都在此频点|
|欧洲及俄罗斯|144.800|保留，IARU R1 Handbook v10.02；采用区域惯例，不冒充逐国核准|

修正了欧洲映射方式：不再仅因法国等主权国家被归类为Europe，就把远方海外领地也赋144.800。海外多边形保留未确认，俄罗斯跨欧亚部分仍采用同一已记录频率惯例。多边形参考点的欧洲窗口为[-32,45]经度、[27,85]纬度，这是剔除远方组件的实现规则，不是国界定义。

|以色列|144.800|IARC 2024公告|

|阿根廷|144.390、144.930|APRS.AR目前说明144.390；LU7系列公开条目出现144.390；AMSAT-LU历史运营资料为144.930。保留两个候选，不推断每格两频都有现役站|

旧APRSISCE频率表（最后编辑2014）仍列泰国145.525，但IARU R3的2018现用备注及泰国HS9DMC运营者页面支持144.390；后者明确划掉145.525。故不把旧频率重新加入泰国网格。

对于韩国144.620等尚未取得足够直接运营证据的地区，继续保留未确认。也没有因为IARU区域通用惯例就把全非洲、中东全部填满。**已经核对的国家频率与每个地点有接收站，是两个不同结论。**

所有已纳入规则的来源地址、证据层级保存在`frequency_rules.json`。低置信度/运营者局部频点映射仅为区域候选，不是精细全国网络调查。

呼号前缀是地区线索，不是本次已验证的精确位置；local count是网关自报统计，不能解释为此刻正在接收的电台数，也不能直接用于覆盖估算。列表包含其他模式的网关，因此1,335不等于1,335个1200 bps VHF接收站。未出现在该列表也不证明没有接收站：未发iGate状态报告、离线或仅RF转发的站可能不在表内。

另外交叉读取了以下具体运营资料：

- [PR2KW-1](https://de.aprs.fi/info/PR2KW-1)：公开索引展示145.570/433.550双频Digi/iGate注释。
- [HP2DFA-6](https://sv.aprs.fi/info/HP2DFA-6)：公开索引展示144.930/145.825，且页面2026-10-03快照有RF直接听到站的统计。145.825是卫星通道，不写入本地VHF网格。
- [LU7前缀条目](https://aprs.fi/info/LU7%2A)：可见LU7FS-10、LU7PB-3等144.390注释；不把其相对年龄当作本次实时状态。
- [MARC站点目录](https://marc.org.za/marc_legacy/pages/freq.htm)：ZS0PMB-2/-3/-5/-6/-7/-8等列144.800，表内也有Down状态；目录本身可能过时。

本次直接请求aprs.fi单站页返回浏览器验证页（虽然HTTP 200），没有获得实时单站数据。上述aprs.fi站点证据来自可读的公开检索快照，不能声称已验证2026-10-09实时在线。findU报告列表与MARC目录则已直接取得。未尝试绕过验证。

## 结论

旧版“无频率”实际上是资料未填或未确认，不是无站；本次已补上有依据的候选。剩余未知区也不能作为停发的覆盖判据。高空气球能接收到邻格/近岸电台，是否有接收机会还取决于高度、距离、地形、天线、链路预算和电台在线情况；本表没有通过站点列表生成覆盖半径。

建议频率候选图继续离线存储；接收站在线情况独立作为带时间的地面参考，不固化为永久禁发区域。
